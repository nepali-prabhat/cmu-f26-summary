Where this data comes from

Lecture topics come from the three schedule/syllabus PDFs embedded in the dn 2026-08-25.md note. 14-642 meets Monday and Wednesday, 12:30–1:50pm — both days show the same published weekly topic, since Canvas doesn't publish one per day. 15-440's three in-recitation quizzes carry the same exam diamond as its midterm and final, since they're graded the same way.

14-642's release and due markers come from its Canvas assignments page. Quizzes list an explicit release date; labs, exercises and the project only publish a due date. An exercise's dashed "window opens" mark is inferred from the previous exercise's due date — not official — and is labelled inferred in its tooltip. Exercise 0 has no predecessor, so it opens on the semester start date.

Progress, notes and completion dates save automatically. The folder icon beside a course code copies that course's local folder path — paste it into Finder's Go to Folder (⌘⇧G).
